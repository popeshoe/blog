# My Blog

My terrible blog, powered by https://gohugo.io/

## Layout & styles

Originally a modified copy of [Hyde](https://github.com/poole/hyde) (built on
[Poole](https://github.com/poole/poole)), both by @mdo and MIT licensed. It was vendored into
`themes/hyde/` rather than forked or submoduled, had diverged substantially, and has now been
flattened into this repo's own `layouts/` and `static/` — so it's no longer a theme in any
meaningful sense. The original MIT licence covers the parts that remain.
